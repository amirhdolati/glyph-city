# Changelog

## Current development

- Added zero-player City Watch with named residents, roles, routines, shelters, conversations, staged public events, and cinematic event-following cameras.
- Added ground-floor glass with furnished interiors for shops, cafes, hotels, lounges, bars, and mature venues.
- Added day/night lighting, rain, storm, mist, reflections, local lamp pools, photo mode, journal, map, boat travel, and persistent album metadata.
- Added an editable in-game settings panel and a generated preview gallery.
- Added optional native audio with continuous ambient layers and scene-aware soundscape refreshes.

The project is experimental and the public repository tracks the current playable milestone.
